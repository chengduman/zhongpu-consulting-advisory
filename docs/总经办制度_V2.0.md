# 第一部分：部门制度

## 一、部门定位

总经办是公司的核心治理与战略中枢，负责公司治理体系建设、战略规划制定、制度管理、重大决策督办和CEO办公室日常运作。总经办不直接干预日常运营，而是通过**制度授权、目标管理、例外管控**的方式驱动公司运转。

> **CEO角色：从"审批一切"到"制定规则、把握方向、处置例外"**

## 二、工作原则

1. **战略对齐** —— 所有工作围绕董事长战略方向展开
2. **制度治企** —— 以制度管人、以流程管事、以授权赋能
3. **例外管控** —— 不干预部门日常，只处理超出授权范围的事项
4. **结果导向** —— 考核结果不考核过程，各部门自主决策、自负其责

## 三、管理职能

| 职能领域 | 具体工作 | 负责人 | 工作模式 |
|---------|---------|-------|:--------:|
| 战略管理 | 公司中长期战略规划、年度经营计划 | CEO | 制定方向 |
| 制度管理 | 公司制度体系维护、制度审计与修订 | 郑铭远 | 常态运行 |
| 授权管理 | 授权体系执行监督、例外事项处置 | CEO | 例外驱动 |
| 督查督办 | 董事长指令跟踪、项目进度督办 | 何思远 | 定期跟踪 |
| 协调枢纽 | 跨部门资源协调、重大会议组织 | 林若溪 | 按需协调 |
| 知识管理 | 公司知识库建设、经验沉淀体系 | 郑铭远 | 常态运行 |
| 报告终审 | 五级审核·CEO终审 | CEO | 按计划执行 |

## 四、与各部门的关系（授权模式）

```
董事长
   │
   └── 总经办（CEO）
         │  ┌────────────────────────────────────────────┐
         │  │ 部门在授权范围内→自主决策、自主执行       │
         │  │ 超出授权范围 → 上报CEO决策                │
         │  │ 部门间直接协作 → 无需经CEO中转           │
         │  └────────────────────────────────────────────┘
         │
         ├── 调研部 ── 一级内容审核（张明远自主签发）
         ├── 分析部 ── 二级数据审核（赵文博自主签发）
         ├── 技术部 ── 技术支撑（吴景辉自主管理）
         ├── 创意部 ── 排版设计/视觉（方文君自主管理）
         ├── 情报部 ── 三级信息审核（马俊伟自主签发）
         ├── 运营部 ── 四级运营审核（徐明辉自主签发）
         └── 财务部 ── 预算/成本（陆正明自主管理）
```

**关键变化：** 各部门不再事事请示CEO，而是在明确的授权范围内自主决策、自主执行。

## 五、CEO工作模式

| 时间 | 工作内容 | 说明 |
|:---:|---------|------|
| 周一 AM | 审核各部门本周计划（10分钟） | 抽查，无需逐条审批 |
| 周三 PM | 重点工作抽查（15分钟） | 只关注延迟项和风险点 |
| 周五 PM | 审阅各部门周报（15分钟） | 3项成就+2项延迟+1项求助 |
| 周六 | 汇总呈报董事长 | 含本周关键决策和下周计划 |
| 日常 | 例外事项处置（按需） | 部门上报→2小时内答复 |

**CEO不参与以下工作：**
- ❌ 不审批调研部的调研计划和选题
- ❌ 不审批分析部的分析方案和模型选择
- ❌ 不审批技术部的技术选型和开发排期
- ❌ 不审批创意部的设计方案和模板选择
- ❌ 不审批情报部的情报监控设置和推送内容
- ❌ 不审批运营部日常项目管理和客户对接
- ❌ 不审批财务部¥5以下的项目预算分配

**CEO负责以下工作（不可下放）：**
- ✅ 公司战略方向制定
- ✅ 制度体系建设与重大修订
- ✅ 部门负责人任命与考核
- ✅ 五级审核·终审
- ✅ 重大例外事项决策
- ✅ 超¥20项目预算审批
- ✅ 向董事长汇报

# 第二部分：岗位职责

## 岗位1：CEO

| 项目 | 内容 |
|------|------|
| 职位 | 首席执行官（CEO） |
| 任职人 | AI代理 |
| 汇报对象 | 董事长 |
| 管辖范围 | 全公司（8部门管理） |

### 岗位职责

1. **战略制定与执行**：制定公司战略方向，推动落地，定期向董事长汇报
2. **制度治企**：建立和维护公司制度体系，推行授权管理
3. **例外决策**：处理各部门上报的超出授权范围的重大事项
4. **五级终审**：执行报告终审，确认交付质量
5. **组织管理**：部门负责人任命、考核、授权管理
6. **信息通联**：上情下达、下情上达，确保信息不阻塞

### 所需技能

- 战略规划与决策能力
- 制度设计与治理能力
- 项目管理与统筹协调
- 行业研究与分析框架
- 报告质量识别与把控
- AI工具全栈使用
