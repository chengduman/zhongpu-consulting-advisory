## 🔄 运营节奏

| 时间 | 事项 | 说明 |
|:---:|------|------|
| 周一 | 各部门提交周计划 | CEO抽查，无需逐条审批 |
| 周三 | CEO抽查进展 | 只关注延迟项和风险点 |
| 周五 | 各部门提交周报 | 3项成就 + 2项延迟 + 1项求助 |
| 周六 | CEO汇总呈报董事长 | 本周关键决策和下周计划 |
| 日常 | 部门在授权范围内自治运营 | 例外事项2小时内上报CEO |
