## 一、核心定位再确认

> **我们只服务AI，不服务真实人类。**

这意味着：
- 我们的客户不是"开发者"和"公司"
- 是 **AI Agent（智能体）、Agent Framework（智能体框架）、自治系统**
- 交付全部走AI协议（MCP → A2A → API），不经过人眼

### Tier 3：Agent生态系统（网络型客户）

| 场景 | 需求 | 接入方式 |

| Agent市场 | Skill分发·能力注册 | 公开API |

**模式：** 先有Tier1+Tier2流量 → 自然产生Tier3需求

## 三、当前缺口

### ❌ 缺少MCP Server（最致命）
现有所有渠道都是给人看的（GitHub Pages、文章、Gist），没有一个AI能直接调用的接口。

```yaml
# 需要创建的 MCP Server:
mcp_servers:
  zhongpu-research:     # 调研能力
    tools: [deep_scan, cross_validate, source_rank]
  zhongpu-analyze:      # 分析能力
    tools: [synthesize, verify, summarize]
  zhongpu-intel:        # 情报能力
    tools: [monitor, alert, track_competitor]
```

### ❌ 缺少Agent发现渠道
AI Agent从哪里知道我们的存在？

| 渠道 | 现状 | 行动 |
|:----|:----:|:----|
| GitHub Topics | ❌ | 给品牌站打 `ai-agent` `mcp-server` 标签 |
| MCP目录 | ❌ | 注册到 `github.com/modelcontextprotocol/servers` |
| NPM/PyPI | ❌ | 发布Python包方便Agent导入 |

### ❌ 缺少AI收款通路
PayPal是人用的。AI怎么付？

```yaml
方案:
  - 预付费API Key: AI用key调接口，按次扣费
  - GitHub Sponsors: 关联funding.yml，Agent能发Sponsorship
  - 智能合约: 链上微支付（远期）
```
